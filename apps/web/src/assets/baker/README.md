# Baker 素材说明

本目录保存 Baker 风格界面实际使用的美术素材。

## 来源与使用边界

- 素材统一整理自《明日方舟：终末地》游戏内资源和森空岛《明日方舟：终末地》相关资料。
- 相关角色、美术和标识的权利归原权利方所有。
- 本项目当前作为非商业玩家二创与学习项目使用这些素材。
- 新增或重命名素材时，应同步更新本文件中的目录职责或显示名映射。

## 目录职责

| 目录             | 用途                                   |
| ---------------- | -------------------------------------- |
| `background/`    | 应用背景                               |
| `navigation/`    | 左侧分类导航图标                       |
| `decoration/`    | 标题、会话卡片、聊天窗口和消息气泡装饰 |
| `avatars/`       | 群聊及演示账号头像                     |
| `avatar-frames/` | 用户可选择的方形头像框                 |
